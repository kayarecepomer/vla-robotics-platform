A low-cost robot learning platform built around a self-printed SO-101 arm: teleoperated data collection with cameras, imitation-learning and VLA baselines, a real-robot evaluation protocol with confidence intervals, an NVIDIA Isaac Sim digital twin, and a study of which frozen vision encoder transfers best to a cheap parallel gripper.

## Research question

[CAIP](https://caip-encoder.github.io/) (Sharma et al., 2026) pre-trains a ViT-L on about 32,000 hours of egocentric human video so its features predict future hand motion, and shows large gains on a 22-DoF dexterous-hand robot. The authors note that transfer to grippers is untested. This project tests it on the cheapest arm there is: the same policy head trained on frozen **SigLIP 2**, **DINOv2** and **CAIP** features, evaluated on the real SO-101 under normal light, changed light and distractor objects. A second ablation pools features only over a text-prompted object mask (OWLv2 + SAM), following [Learning to Grasp Anything by Playing with Random Toys](https://lego-grasp.github.io/) (ICLR 2026). Design and run steps: [docs/ENCODER_STUDY.md](docs/ENCODER_STUDY.md).

## What's in the repo

| Path | What it does | Runs on |
|---|---|---|
| `bridge/joint_state.py` | Typed joint-state message, binary and JSON codecs | both |
| `bridge/policy_protocol.py` | Observation → action-chunk wire format (JSON header + JPEG frames + float32 actions) | both |
| `bridge/calibration.py`, `config/so101_twin_mapping.json` | Calibrated joint readings and raw Feetech ticks → Isaac Sim joint radians | both |
| `bridge/mac/publisher.py` | Streams the calibrated leader arm at 60 Hz | Mac |
| `bridge/mac/policy_client.py` | Executes a remote policy on the follower, measures round-trip latency, optionally mirrors to the twin | Mac |
| `bridge/windows/policy_server.py` | Hosts ACT / SmolVLA / study checkpoints on the GPU | Windows |
| `sim/so101_scene.py`, `sim/mirror.py` | Rebuilds the Isaac Sim scene from code; mirrors the real arm live or replays a recorded episode | Windows (Isaac Sim) |
| `scripts/record_dataset.sh` | Records camera + joint demos into a LeRobotDataset and pushes to the Hub | Mac |
| `scripts/train_baselines.ps1` | Trains ACT and fine-tunes SmolVLA with `lerobot-train` | Windows |
| `vla/eval/` | Grid-based real-robot evaluation, printable placement sheet, logged trials, results table | Mac |
| `vla/encoders/`, `vla/study/`, `scripts/run_encoder_study.ps1` | Frozen-encoder feature caching, mask pooling, shared transformer policy head | Windows |
| `vla/dagger.py` | Leader-arm DAgger: take over when the policy fails and record the correction | Mac |

Step-by-step commands for both machines: [docs/RUNBOOK.md](docs/RUNBOOK.md).
