## 4. Operational Execution & Workflow Commands

All commands are executed from the root repository directory `/Users/omerkaya/lerobot` with the `lerobot` conda environment active.

### 4.1 Live Real-Time Teleoperation
To launch low-latency (60 FPS) teleoperation pairing `kayas_leader` with `kayas_follower`:

```zsh
python src/lerobot/scripts/lerobot_teleoperate.py \
  --robot.type=so101_follower \
  --robot.port=/dev/tty.usbmodem5B610352021 \
  --robot.id=kayas_follower \
  --teleop.type=so101_leader \
  --teleop.port=/dev/tty.usbmodem5B610373041 \
  --teleop.id=kayas_leader
```

### 4.2 Handling Motor Lockup / Disarming Followers
When exiting teleoperation (`Ctrl + C`), the STS3215 servos may remain under holding torque or trigger stall protection:
* **Hardware Disarm:** Disconnect the 12V DC power barrel jack from the Waveshare board for 3 seconds.
* **Software Disarm Script:**
```zsh
python -c "from lerobot.teleoperators.so_leader.so_leader import FeetechMotorsBus; bus = FeetechMotorsBus(port='/dev/tty.usbmodem5B610352021', motors={'shoulder_pan': (1, 'sts3215'), 'shoulder_lift': (2, 'sts3215'), 'elbow_flex': (3, 'sts3215'), 'wrist_flex': (4, 'sts3215'), 'wrist_roll': (5, 'sts3215'), 'gripper': (6, 'sts3215')}); bus.connect(); bus.write('Torque_Enable', 0); bus.disconnect()"
```

### 4.3 Joint Re-Calibration Protocol
If physical servo horn alignment or cable tensions change:
1. **Follower Calibration:**
   ```zsh
   lerobot-calibrate --robot.type=so101_follower --robot.port=/dev/tty.usbmodem5B610352021 --robot.id=kayas_follower
   ```
2. **Leader Calibration:**
   ```zsh
   lerobot-calibrate --teleop.type=so101_leader --teleop.port=/dev/tty.usbmodem5B610373041 --teleop.id=kayas_leader
   ```
* **Protocol Rule:** Place both arms in the exact same physical upright 90-degree "L-shape" with grippers fully closed when confirming the starting midpoint prompt before sweeping through full ranges.

## 5. Additive Manufacturing & Mechanical Parameters (Bambu Lab A1)

To eliminate base flaring (Elephant's Foot) and prevent rough/crunchy lower-layer overhang sagging on 3D-printed parts:

### 5.1 Slicer Process & Speed Configuration (Bambu Studio)
* **Preset Profile:** 0.20mm Strength @ BBL A1.
* **Precision / Elephant Foot Compensation:** Set to `0.25 mm` - `0.30 mm` (Process -> Quality -> Precision).
* **Speed Profile Adjustments (Process -> Speed):**
  * Outer Wall Speed: `60 mm/s`
  * Inner Wall Speed: `300 mm/s`
  * Initial Layer Speed: `50 mm/s`
  * Initial Layer Infill: `105 mm/s`
  * Overhang 10%: `0 mm/s` (default wall speed)
  * Overhang 25%: `30 mm/s`
  * Overhang 50%: `30 mm/s`
  * Overhang 75%: `15 mm/s`

### 5.2 Cooling & Filament Thermals (Creality Hyper/Ultra PLA)
* **Textured PEI Heatbed Temperature:** `55°C` (preventing soft base spreading).
* **Flow Ratio:** `0.94` - `0.95` (calibrated down from 0.98 to stop solid infill over-extrusion).
* **Part Cooling Fan:**
  * Max fan speed threshold: `100%`
  * Cooling overhang threshold: `25%` (triggers 100% fan earlier on shallower slopes).
  * Fan speed for overhangs: `100%`
  * Force cooling for overhangs and bridges: **Checked**

### 5.3 Support Interface Settings (Process -> Support)
* **Support Type:** Normal (auto) with **Snug** style or **Tree Hybrid**.
* **Top Z Distance:** `0.18 mm` - `0.20 mm` (prevents molten plastic dropping into thin air).
* **Top Interface Layers:** `3`
* **Top Interface Spacing:** `0.2 mm` - `0.3 mm` (solid support ceiling).

### 7.1 Core Research Projects

#### Project 1: Closed-Loop Agentic Manipulation with Multimodal Failure Recovery
* Implement a Python-based autonomous agent using LangGraph / AutoGen.
* The agent captures multi-view RGB-D camera frames, detects task affordances using Grounding DINO / SAM, dispatches actuation primitives, and assesses post-execution state to detect and correct grasping errors.

#### Project 2: Sim-to-Real Policy Transfer via Isaac Sim Domain Randomization
* Build a USD digital twin of the SO-101 in Isaac Sim on the Windows workstation.
* Generate thousands of domain-randomized rollouts (varying lighting, camera positions, friction, object scales).
* Train an **Action Chunking with Transformers (ACT)** policy and deploy zero-shot to the physical Mac-connected SO-101 arm.

#### Project 3: Real-Time Multimodal Teleoperation & Data Harvesting
* Utilize the synchronized leader-follower setup to record demonstration datasets stored in LeRobot dataset format (`Hugging Face LeRobotDataset`).
* Stream video observations and proprioceptive states directly into cloud/local training pipelines.
